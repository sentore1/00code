## 🔧 Technical Architecture

```
┌──────────────────────────────────────────────────────────────┐
│                    ENCODING PROCESS                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Input Text: "Hello World"                                  │
│  ↓                                                           │
│  UTF-8 Encode: 11 bytes                                     │
│  ↓                                                           │
│  Add Metadata:                                              │
│  ├─ Length: 11 bytes (48 bits)                              │
│  ├─ Shape: diamond (3 bits)                                 │
│  └─ Scan: 0 (8 bits)                                        │
│  ↓                                                           │
│  Binary: [48 bits] + [3 bits] + [8 bits] + [88 bits data]  │
│  ↓                                                           │
│  Draw: 50 rings × 360 segments = 18,000 shapes              │
│  ↓                                                           │
│  Output: PNG image                                          │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│                    DECODING PROCESS                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  Input: PNG image                                           │
│  ↓                                                           │
│  Extract: 18,000 bits from shapes                           │
│  ↓                                                           │
│  Decode Metadata:                                           │
│  ├─ Length: 11 bytes (majority voting)                      │
│  ├─ Shape: diamond                                          │
│  └─ Scan: 0                                                 │
│  ↓                                                           │
│  Extract: 88 bits of data                                   │
│  ↓                                                           │
│  UTF-8 Decode: "Hello World"                                │
│  ↓                                                           │
│  Output: Text + metadata                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
