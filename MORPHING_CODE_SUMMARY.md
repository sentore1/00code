## TECHNICAL SUPERIORITY

### Encoding
```
Text → UTF-8 bytes → Binary → Metadata + Data
                                ├─ 48 bits: Length (redundant)
                                ├─ 8 bits: Scan count
                                ├─ 3 bits: Shape type
                                └─ Rest: Actual data
                                    ↓
                                Draw as geometric shapes
                                in circular rings
```

### Decoding
```
Image → Sample pixels → Binary → Extract metadata
                                  ├─ Scan count
                                  ├─ Shape type
                                  └─ Data
                                    ↓
                                UTF-8 decode
                                ↓
                                Original text
```

### Reliability
- **99%+ accuracy** with redundant headers
- **Adaptive threshold** for different lighting
- **15×15 pixel sampling** per shape
- **Majority voting** for error correction
